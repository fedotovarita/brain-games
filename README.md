# Проект «Ігри розуму»
«Ігри розуму» — набір із п'яти консольних ігор, побудованих за принципом популярних мобільних додатків для прокачування мозку. Кожна гра задає питання, на які потрібно дати правильні відповіді. Після трьох правильних відповідей вважається, що гра пройдена. Неправильні відповіді завершують гру і пропонують пройти її заново. Ігри:

### Ігри:
1. Калькулятор. Арифметичні вирази, які необхідно обчислити.
2. Прогресія. Пошук пропущених чисел у послідовності чисел.
3. Визначення парного числа.
4. Визначення найбільшого спільного дільника.
5. Визначення простого числа.
